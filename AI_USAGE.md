# AI / SI tool usage disclosure

Per the NASA Space Apps Challenge 2026 rules on the use of SI (AI) tools.

## What was AI-assisted

**Claude Code** (Anthropic, Claude Sonnet 5 / 5.5) was used throughout this project's
implementation: the data pipeline (FIRMS fetch, filtering, H3 aggregation,
cross-sensor calibration, validation), the web app (React, MapLibre, deck.gl, D3),
the deployment configuration, the supporting plots, and the documentation and
submission texts. Git
commit history carries a `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`
trailer on every AI-assisted commit as per-commit metadata.

## AI-generated images (labelled on the site)

The inner-page background (an eclipse-style glow), the same image behind the front page's About section, and the glowing-tree picture in the
"When does your region burn?" panel were **generated with ChatGPT**. Each carries a visible label on the site: "SI-generated background image (ChatGPT)" or
"SI-generated image (ChatGPT)". The front-page hero (volcano) is a real photograph, not AI-generated. Screenshots in `docs/submission/` that show the
AI backgrounds therefore also show the label. No NASA logo, flag or mission identifier is used or modified anywhere.

## What was not AI-generated

- **Direction and decisions.** The team set the goal and made the design decisions (burning cell-days on an H3 grid, calibrating
  Aqua against VIIRS on their overlap, validating against independent burned-area data, the feature set). A planning conversation
  with Claude (claude.ai) was used to discuss options and draft the plan, and Claude Code to implement it. Judges should read the
  idea as developed with AI assistance in planning, under the team's direction.
- **The data** — all active-fire detections come from NASA FIRMS (MODIS and
  VIIRS instruments); nothing in the dataset is synthetic or AI-generated.
- **Charts, screenshots and the architecture diagram** (`docs/`, `docs/submission/`) are empirical visualizations of that real satellite
  data, generated by ordinary plotting or screenshot code (matplotlib, a browser), or hand-written HTML/CSS (the architecture diagram), — not by a
  generative image model. Where a screenshot contains one of the ChatGPT-generated backgrounds above, the on-site label is visible in it or
  noted in its caption.

## If generative images/video/audio are added later

Any hero image, demo-video b-roll, narration, or similar asset produced with
a generative model before submission must:
- carry a visible watermark (images/video), or
- be acknowledged in descriptive text + metadata (audio),

and must not use or modify any NASA logo, flag, or mission identifier.
