# AI / SI tool usage disclosure

Per the NASA Space Apps Challenge 2026 rules on the use of SI (AI) tools.

## What was AI-assisted

**Claude Code** (Anthropic, Claude Sonnet 5) was used throughout this project's
implementation: the data pipeline (FIRMS fetch, filtering, H3 aggregation,
cross-sensor calibration), supporting plots, and this documentation. Git
commit history carries a `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`
trailer on every AI-assisted commit as per-commit metadata.

## What was not AI-generated

- **The challenge solution itself** — the decision to build a burning-activity
  calendar on an H3 grid using "burning cell-days," the choice to calibrate
  MODIS Aqua against VIIRS S-NPP on their 2012+ overlap, the feature set, and
  the overall architecture — was specified by the project author before any
  code was written. AI was used to implement that design, not to originate it.
- **The data** — all active-fire detections come from NASA FIRMS (MODIS and
  VIIRS instruments); nothing in the dataset is synthetic or AI-generated.
- **Charts in `docs/`** are empirical visualizations of that real satellite
  data, generated by ordinary plotting code (matplotlib) — not by a
  generative image model, so they don't carry a watermark per the rules
  (which require one only for AI-*generated* images/video).

## If generative images/video/audio are added later

Any hero image, demo-video b-roll, narration, or similar asset produced with
a generative model before submission must:
- carry a visible watermark (images/video), or
- be acknowledged in descriptive text + metadata (audio),

and must not use or modify any NASA logo, flag, or mission identifier.
